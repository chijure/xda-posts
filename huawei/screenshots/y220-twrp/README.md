# TWRP Huawei Y220-U05 screenshots

Capturas reales del framebuffer del Y220-U05 a 320x480. El canal alfa del
framebuffer fue eliminado para que los colores se vean correctamente sobre
cualquier fondo al publicarlas.

## Capturas recomendadas

1. `01-main-menu.png`: menú principal y versión `3.1.1-0.1 by chijure`.
2. `02-install.png`: selector de ZIP sobre la microSD externa.
3. `03-backup.png`: interfaz de backup.
4. `04-mount.png`: selector de particiones UBIFS y microSD.
5. `05-settings.png`: ajustes generales de TWRP.

Durante las capturas no se ejecutó instalación, wipe, backup ni restore. Solo
se abrieron las pantallas y se regresó con Back.

Subir las imágenes a un alojamiento público y sustituir los marcadores
`PUT_*_SCREENSHOT_URL_HERE` del post BBCode.
